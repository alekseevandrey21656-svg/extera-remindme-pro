# extera-remindme-pro
Умный таск-менеджер для exteraGram. Парсит дату и время из обычной речи (.remind завтра в 15:00), автоматически ставит отложенные напоминания Telegram и предоставляет GUI-календарь прямо в чате. Позволяет просматривать задачи, управлять ими и планировать дела в пару кликов. Чистый открытый код без внешних зависимостей.
