# RemindMe Pro

Умный таск-менеджер для **exteraGram**. Парсит даты и время из обычной речи, отправляет отложенные напоминания и предоставляет удобный текстовый календарь прямо в чате.

---

## Возможности:
- **NLP-парсинг времени:** Понимает фразы вроде `.remind через 15 мин` или `.remind завтра в 18:00`.
- **Идеальный UI:** Текстовый моноширинный календарь, сохраняющий ровную сетку на любых экранах и в диалогах.
- **Высокая производительность:** Фоновая асинхронная запись на диск (`asyncio.to_thread`) без подлагиваний интерфейса.
- **Чистый код:** Полная совместимость со стандартами `BasePlugin`.

---

## Использование:

- `.remind [время] [текст]` — создать новое напоминание.
- `.remind cal` — открыть календарь на текущий месяц.
- `.remind cal [месяц] [год]` — открыть календарь на выбранную дату (например, `.remind cal 10 2026`).

## Список изменений (Changelog):

### v2.0.0
- **UI:** Перевод календаря на моноширинные HTML-теги `<tt>` для исправления съехавшей сетки в диалоговых окнах Android.
- **Производительность:** Оптимизация записи в `remind_me_data.json` через фоновые потоки (`asyncio.to_thread`).
- **Архитектура:** Переработка плагина под класс `RemindMePlugin(BasePlugin)` с поддержкой хуков `on_plugin_load` и `on_plugin_unload`.
- **Переработка:** Полная очистка от устаревших зависимостей и шаблонного кода.
